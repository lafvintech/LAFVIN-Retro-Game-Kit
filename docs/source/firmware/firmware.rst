.. _firmware:

================
固件烧录
================

概述
====

LAFVIN Retro Game Kit 使用开源固件,需要用户将固件烧录到 ESP32S3 主控模块才能正常工作。本章节将指导您完成固件的下载、烧录和验证过程。

.. note::
   固件烧录是一次性操作,除非需要更新固件版本,否则无需重复烧录。

什么是固件烧录?
================

固件是运行在 ESP32S3 芯片上的软件程序,它控制着游戏机的所有功能,包括:

- 游戏模拟器引擎
- 显示屏驱动
- 音频输出控制
- 按键输入处理
- TF 卡文件系统管理
- 菜单系统和用户界面

烧录固件就是将这个程序写入到 ESP32S3 的 Flash 存储器中的过程。

准备工作
========

在开始烧录固件之前,请确保您已准备好以下物品:

硬件准备
--------

- ESP32S3N16R8 主控模块
- Type-C 数据线(支持数据传输,不能只是充电线)
- 电脑(Windows、macOS 或 Linux)

软件准备
--------

- 固件文件(.bin 格式)
- 烧录工具(esptool 或 ESP Flash Download Tool)
- USB 驱动程序(部分系统需要)

.. warning::
   请使用支持数据传输的 Type-C 线,仅支持充电的线缆无法进行固件烧录!

烧录流程
========

固件烧录的基本流程如下:

1. **下载固件** - 获取最新版本的固件文件
2. **安装烧录工具** - 准备固件烧录工具
3. **连接设备** - 将 ESP32S3 通过 Type-C 线连接到电脑
4. **配置参数** - 设置烧录地址和参数
5. **开始烧录** - 执行烧录操作
6. **验证成功** - 确认固件烧录成功
