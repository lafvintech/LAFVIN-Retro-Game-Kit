============
组装教程
============

欢迎来到 LAFVIN Retro Game Kit 组装教程!本教程将指导您一步步完成游戏机的硬件组装。

组装概述
========

组装 LAFVIN Retro Game Kit 需要约 30-60 分钟。整个过程包括面包板准备、模块安装、按键安装和跳线连接。请仔细阅读每个步骤,并按照顺序进行操作。

.. warning::
   在组装过程中,请确保所有模块处于断电状态。请勿在通电状态下插拔模块,可能导致硬件损坏!

所需工具
========

- 无需焊接工具
- 建议准备:镊子(用于整理跳线)
- 良好的照明环境
- 平整的工作台面

组装前准备
==========

在开始组装前,请确认您已收到以下所有组件:

- ESP32S3N16R8 主控模块 × 1
- LAFVIN TFCard 模块 × 1
- LAFVIN 功放模块 × 1
- LAFVIN Retro game 扩展底板 × 1
- 2.8 英寸 TFT 显示屏 × 1
- 280 面包板 × 2
- 小按钮(6×6mm) × 10
- 大按钮(12×12mm) × 4
- 按钮帽 × 4
- 硬质跳线若干
- 软质公对公跳线若干

详细清单请参考 :doc:`component_list`。

步骤 2: 模块安装
================

接下来,我们将安装主要的功能模块。

2.1 安装 ESP32S3 主控模块
-------------------------

ESP32S3N16R8 是整个游戏机的核心控制器。

**安装步骤:**

1. 找到 ESP32S3N16R8 主控模块
2. 将模块插入扩展底板的主控插槽
3. 确保所有引脚完全插入,模块与底板紧密贴合
4. 注意模块的方向,USB Type-C 接口应朝向便于连接的方向

.. image:: ./img/assembly/esp32s3_installation.jpg
   :alt: ESP32S3 主控模块安装
   :align: center
   :width: 600px

[占位符:需要 ESP32S3 模块安装到扩展底板的图片]

.. warning::
   安装时请勿用力过猛,避免损坏引脚。如果引脚无法顺利插入,请检查引脚是否对齐。

2.2 安装 TFCard 模块
--------------------

TFCard 模块用于读取游戏文件。

**安装步骤:**

1. 找到 LAFVIN TFCard 模块
2. 将模块插入面包板的合适位置(靠近主控模块)
3. 确保模块的引脚完全插入面包板的插孔中
4. TF 卡插槽应朝外,便于插拔 TF 卡

.. image:: ./img/assembly/tfcard_installation.jpg
   :alt: TFCard 模块安装
   :align: center
   :width: 600px

[占位符:需要 TFCard 模块安装位置的图片]

.. tip::
   TFCard 模块的卡槽方向很重要,确保 TF 卡可以方便地插入和取出。

2.3 安装功放模块
----------------

功放模块负责音频输出。

**安装步骤:**

1. 找到 LAFVIN 功放模块
2. 将模块插入面包板的合适位置
3. 确保音频输出接口(3.5mm 耳机孔或扬声器接口)朝外
4. 检查模块是否稳固

.. image:: ./img/assembly/amplifier_installation.jpg
   :alt: 功放模块安装
   :align: center
   :width: 600px

[占位符:需要功放模块安装位置的图片]

2.4 安装 TFT 显示屏
-------------------

2.8 英寸 TFT 显示屏是游戏画面的输出设备。

**安装步骤:**

1. 找到 2.8 英寸 TFT 显示屏模块
2. 小心地将显示屏的排线或引脚连接到扩展底板的显示接口
3. 如果是排线连接,确保排线插入到位并锁紧
4. 将显示屏固定在合适的位置

.. image:: ./img/assembly/tft_installation.jpg
   :alt: TFT 显示屏安装
   :align: center
   :width: 600px

[占位符:需要 TFT 显示屏安装和连接的图片]

.. warning::
   显示屏排线较为脆弱,请轻柔操作。插入排线时确保方向正确,不要反向插入。

步骤 3: 按键安装
================

游戏机需要安装 14 个按键用于游戏控制和系统操作。

3.1 安装小按钮(10 个)
----------------------

小按钮(6×6mm)用于方向控制和部分功能键。

**安装位置:**

- 方向键:上、下、左、右(4 个)
- 功能键:Select、Start、Menu、Option(4 个)
- 其他功能键(2 个)

**安装步骤:**

1. 将小按钮插入面包板的指定位置
2. 按钮的四个引脚应完全插入面包板
3. 确保按钮按压时手感正常,无卡顿

.. image:: ./img/assembly/small_buttons_layout.jpg
   :alt: 小按钮布局示意图
   :align: center
   :width: 600px

[占位符:需要 10 个小按钮在面包板上的布局图片]

.. note::
   方向键建议按照十字形布局,便于操作。功能键应放置在便于按压的位置。

3.2 安装大按钮(4 个)
---------------------

大按钮(12×12mm)用于主要游戏操作。

**安装位置:**

- A 键(确认/跳跃)
- B 键(取消/攻击)
- 预留功能键 × 2

**安装步骤:**

1. 将大按钮插入面包板的指定位置
2. 为大按钮安装按钮帽,提升手感
3. 确保按钮间距合理,便于操作

.. image:: ./img/assembly/large_buttons_layout.jpg
   :alt: 大按钮布局示意图
   :align: center
   :width: 600px

[占位符:需要 4 个大按钮在面包板上的布局图片,包含按钮帽]

.. tip::
   A 和 B 键建议采用横向或斜向排列,符合人体工程学设计。

3.3 按键布局建议
----------------

推荐的按键布局:

.. code-block:: text

   左侧区域:              右侧区域:
   
        ↑                    [Y]  [X]
      ← + →                  [B]  [A]
        ↓
   
   [Select] [Start]      [Menu] [Option]

步骤 4: 跳线连接
================

跳线连接是组装过程中最关键的步骤,需要仔细核对每个连接。

4.1 电源和地线连接
------------------

首先连接电源和地线,为所有模块提供供电。

**连接步骤:**

1. 将 ESP32S3 的 3.3V 引脚连接到面包板的正电源轨(红色)
2. 将 ESP32S3 的 GND 引脚连接到面包板的负电源轨(蓝色)
3. 确保两块面包板的电源轨互相连接

.. warning::
   电源连接错误可能导致模块损坏!请务必确认 3.3V 和 GND 连接正确。

4.2 TFT 显示屏引脚连接
----------------------

TFT 显示屏需要连接多个引脚用于数据传输和控制。

     - 地线
   * - CS
     - GPIO 5
     - 片选信号
   * - RESET
     - GPIO 17
     - 复位信号
   * - DC
     - GPIO 16
     - 数据/命令选择
   * - MOSI
     - GPIO 23

     - SPI 时钟
   * - LED
     - GPIO 15

   * - MISO

4.4 功放模块引脚连接
--------------------

功放模块负责音频输出。

.. list-table:: 功放模块引脚对应表

     - 地线
   * - DIN

     - I2S 数据输入

     - I2S 位时钟

     - GPIO 27

.. note::
   功放模块需要 5V 供电,请从 ESP32S3 的 5V 引脚或 USB 供电获取。

4.5 按键引脚连接
----------------

所有按键需要连接到 ESP32S3 的 GPIO 引脚。

     - 右方向

4.6 跳线整理
------------

完成所有连接后,整理跳线:

1. 使用不同颜色的跳线区分电源、地线和信号线
2. 建议:红色 = 电源,黑色 = 地线,其他颜色 = 信号线
3. 尽量保持跳线整齐,避免交叉缠绕
4. 使用镊子调整跳线位置

.. tip::
   整齐的跳线布局不仅美观,还便于后续的故障排查和维护。

5.3 通电前最后确认
------------------

   2. 无短路现象
   3. 所有模块安装牢固
   
   如有任何疑问,请勿通电,先检查连接!

常见问题
========

**Q: 组装时引脚插不进去怎么办?**

A: 请勿用力过猛。检查引脚是否对齐,可以轻轻调整引脚角度。如果引脚弯曲,可以小心地用镊子调整。

**Q: 跳线太多,容易搞混怎么办?**

A: 建议使用不同颜色的跳线,并且一次只连接一个模块,连接完成后再进行下一个模块。

**Q: 按键需要焊接吗?**

A: 不需要。所有按键都是插入式设计,直接插入面包板即可。

**Q: 可以调整按键布局吗?**

A: 可以。您可以根据个人习惯调整按键位置,但需要相应修改固件中的引脚配置。

**Q: 组装完成后如何测试?**

A: 请先完成固件烧录,然后按照使用说明进行测试。详见 :doc:`firmware/firmware` 和 :doc:`usage/usage`。
