============
菜单系统说明
============

菜单概述
========

LAFVIN Retro Game Kit 提供了直观的菜单系统,让您可以轻松浏览和选择游戏、调整设置。

主菜单界面
==========

.. image:: ../img/usage/main_menu.jpg
   :alt: 主菜单界面
   :align: center
   :width: 600px

[占位符:需要主菜单界面截图,显示菜单选项和布局]

主菜单包含以下选项:

- **游戏库**: 浏览和选择游戏
- **最近游戏**: 查看最近玩过的游戏
- **设置**: 调整系统设置
- **关于**: 查看系统信息

菜单导航
========

使用按键浏览菜单
----------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 操作
     - 按键
   * - 向上移动

   * - 向左移动/返回上级
     - 方向键(左)或 B 键
   * - 向右移动/进入子菜单
     - 方向键(右)或 A 键
   * - 确认选择
     - A 键
   * - 取消/返回
     - B 键
   * - 打开菜单
     - Menu 键

游戏库浏览
==========

选择游戏平台
------------

1. 在主菜单中选择 **游戏库**
2. 使用方向键选择游戏平台(NES、SNES、GB、GBC 等)
3. 按 A 键进入该平台的游戏列表

.. image:: ../img/usage/game_library.jpg
   :alt: 游戏库界面
   :align: center
   :width: 600px

[占位符:需要游戏库界面截图,显示不同游戏平台的图标]

浏览游戏列表
------------

1. 使用方向键(上/下)浏览游戏列表
2. 游戏列表会显示游戏名称和缩略图(如果有)
3. 按 A 键启动选中的游戏
4. 按 B 键返回平台选择界面

.. note::
   游戏列表会自动读取 TF 卡中对应文件夹的游戏文件。如果列表为空,请检查 TF 卡中是否已添加游戏文件。

游戏中菜单
==========

在游戏运行时的菜单操作
----------------------

在游戏运行过程中,您可以按 **Menu 键** 打开游戏中菜单:

.. image:: ../img/usage/in_game_menu.jpg
   :alt: 游戏中菜单
   :align: center
   :width: 600px

[占位符:需要游戏中菜单截图,显示暂停菜单选项]

游戏中菜单选项:

- **继续游戏**: 返回游戏
- **保存进度**: 保存当前游戏状态(如果支持)
- **加载进度**: 加载之前保存的游戏状态(如果支持)
- **设置**: 调整游戏设置
- **返回主菜单**: 退出游戏返回主菜单

.. warning::
   返回主菜单前请确保已保存游戏进度,否则未保存的进度将丢失。

快速操作
========

为了提高使用效率,系统提供了一些快速操作:

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - 快速操作
     - 说明
   * - 长按 Menu 键
     - 直接返回主菜单
   * - Menu + Start
     - 快速保存游戏进度
   * - Menu + Select
     - 快速加载游戏进度
   * - 双击 Menu 键
     - 显示最近游戏列表

.. tip::
   熟练使用快速操作可以大大提升使用体验!
