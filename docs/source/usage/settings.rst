设置菜单概述
============

本系统提供两个独立的设置菜单，各有不同的功能：

.. list-table:: 两种菜单对比
   :header-rows: 1
   :widths: 20 40 40

   * - 菜单类型
     - 功能说明
     - 打开方式
   * - **Option 菜单**
     - 系统全局设置（音量、亮度、语言、主题等）
     - 按 **Option** 按键
   * - **Menu 菜单**
     - 游戏内操作（存档、读档等）
     - 游戏中按 **Menu** 按键

   - **Menu 菜单**：仅在游戏运行时可用，用于游戏内操作

音量调节
========

调节音量大小
------------

**操作步骤：**

1. 按 **Option** 按键打开系统菜单
2. 选择 **Volume（音量）** 选项
3. 使用方向键（左/右）调节音量大小
4. 音量范围：0-100（0 为静音，100 为最大音量）
5. 按 **B** 键返回并自动保存设置

.. tip::
   音量设置会立即生效，您可以边调节边试听效果。

亮度调节
========

调节屏幕亮度
------------

**操作步骤：**

1. 按 **Option** 按键打开系统菜单
2. 选择 **Brightness（亮度）** 选项
3. 使用方向键（左/右）调节屏幕亮度
4. 亮度范围：0-100（建议设置在 60-80 之间）
5. 按 **B** 键返回并自动保存设置

.. list-table:: 亮度调节快捷操作
   :header-rows: 1
   :widths: 30 70

   * - 操作
     - 说明
   * - 方向键（右）
     - 增加亮度（+5）
   * - 方向键（左）
     - 减少亮度（-5）
   * - B 键
     - 保存并返回

.. tip::
   - 较低的亮度可以延长使用时间（使用移动电源时）
   - 建议根据环境光线调整亮度，避免眼睛疲劳

游戏速度调节
============

调节游戏运行速度
----------------

在某些情况下，您可能需要调整游戏的运行速度（如练习难关或快速通关）。

**操作步骤：**

1. 在游戏中按 **Option** 按键打开菜单
2. 选择 **Speed（速度）** 选项
3. 使用方向键（左/右）选择速度倍率
4. 可选速度：0.5x 、1.0x（正常）、1.5x、2.0x
5. 按 **B** 键返回并保存设置

.. list-table:: 速度倍率说明
   :header-rows: 1
   :widths: 20 80

   * - 速度倍率
     - 适用场景
   * - 0.5x
     - 慢速模式，适合练习难度较高的关卡或精确操作
   * - 1.0x
     - 正常速度（默认），原汁原味的游戏体验
   * - 1.5x
     - 快速模式，适合重复关卡
   * - 2.0x
     - 超快模式，适合快速通关或跳过剧情

.. warning::
   - 修改游戏速度可能会影响音频同步和游戏体验
   - 某些游戏在非正常速度下可能出现卡顿或异常
   - 建议在正常速度（1.0x）下游玩以获得最佳体验

语言切换
========

切换界面语言
------------

系统支持多种界面语言，方便不同地区的用户使用。

**操作步骤：**

1. 按 **Option** 按键打开系统菜单
2. 选择 **Language（语言）** 选项
3. 按 **A** 键进入语言选择子菜单
4. 使用方向键（上/下）浏览可用语言
5. 按 **A** 键确认选择，系统会自动切换语言并返回主界面

     - Japanese

   * - Deutsch

   * - Français

.. note::

   - 不影响游戏内容的语言（游戏语言由 ROM 本身决定）
   - 语言设置会立即生效并自动保存
