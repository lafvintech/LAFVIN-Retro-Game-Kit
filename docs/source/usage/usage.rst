使用说明
============

欢迎使用 LAFVIN Retro Game Kit!本章节将指导您如何使用游戏机,包括开机、按键操作、菜单系统、设置调节和模拟器使用。

概述
====

LAFVIN Retro Game Kit 是一款基于 ESP32S3 的复古游戏机,支持多种经典游戏平台。通过 Type-C 接口供电,使用 2.8 英寸 TFT 屏幕显示,配备完整的游戏按键和音频输出。

主要功能
--------

- **多平台支持**: 支持 NES、SNES、GB、GBC、SMS、GG、MD、PCE、LYNX、DOOM 等多个游戏平台
- **便捷操作**: 直观的按键布局和菜单系统
- **灵活设置**: 可调节音量、亮度、游戏速度和界面语言
- **TF 卡存储**: 支持大容量 TF 卡,可存储大量游戏
- **即插即用**: Type-C 供电,无需复杂设置

快速开始
========

1. **供电开机**: 使用 Type-C 线连接电源,详见 :doc:`power_on`
2. **了解按键**: 熟悉游戏控制按键和系统功能按键,详见 :doc:`buttons`
3. **使用菜单**: 学习如何浏览和选择游戏,详见 :doc:`menu`
4. **调节设置**: 根据需要调整音量、亮度等设置,详见 :doc:`settings`
5. **选择模拟器**: 了解各个模拟器的使用方法,详见 :doc:`emulators`

.. note::
   首次使用前,请确保已完成硬件组装和固件烧录,并准备好 TF 卡。

使用流程
========

基本使用流程如下:

1. 连接 Type-C 电源线
2. 系统自动开机并显示主菜单
3. 使用方向键浏览游戏列表
4. 按 A 键选择游戏
5. 游戏运行后使用游戏按键进行操作
6. 按 Menu 键可返回主菜单或调整设置

常见问题
========

**Q: 如何返回主菜单?**

A: 在游戏中按 Menu 键即可返回主菜单。

**Q: 如何调节音量?**

A: 按 Menu 键打开菜单,选择"设置"选项,然后选择"音量"进行调节。详见 :doc:`settings`。

**Q: 游戏运行速度太快或太慢怎么办?**

A: 可以在设置中调节游戏速度。详见 :doc:`settings`。

**Q: 如何切换界面语言?**

A: 在设置菜单中选择"语言"选项,可以在英语、德语、法语之间切换。详见 :doc:`settings`。
